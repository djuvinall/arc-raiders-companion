This version adds in-app updates, so it's the last one you need to download by hand.

## Install

Download `ARC-Raiders-Companion-v0.2.0-setup.exe` below and run it. It installs for your user only and needs no admin rights. The installer isn't code-signed yet, so SmartScreen may warn you: choose **More info**, then **Run anyway**. Your profile carries over from v0.1.0, and you can delete the old exe afterwards.

## New

- **In-app updates:** the app checks GitHub when it starts and offers new versions with one click.
- **Item data updates:** new data arrives without a new version of the app.
- **Items:** each gun is one entry, with level and amplification controls and changes shown against the base version.
- **Stencils:** approximate previews on every gun a stencil fits, your own screenshots, how to get each stencil and its Stencil Parts cost. Gun pages list the stencils that fit.
- **Blueprints:** the blueprint background, Mark found, and filters to hide blueprints or found items.

Stencil weapon lists, sources and costs are community-reported, so confirm them in game.
