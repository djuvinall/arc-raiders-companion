This update arrives through the app: click **Update now** when the banner appears.

## New

- **Suggest a map.** The Raid page ranks every map for what you're tracking, the quest steps there and the conditions live on it right now, then opens a plan on the one you pick.
- **Primary objective.** Pick a quest step, an ARC to hunt, a place or a marker as the reason for the raid. Side areas are ranked by what they give you against how far they are from it, and each loop passes it.
- **Live conditions change the plan.** While a condition such as Night Raid or Uncovered Caches is on, the plan counts its better loot, the extra containers it spawns and its event-only caches. The plan shows what's live and what it changes.
- **Quest catch-up.** **Pick my current quests** tracks several quests at once, and tracking a quest with unfinished earlier ones offers to mark those done. **I'm on this one** marks everything before a quest done and keeps it tracked.
- **Friends' quests between code swaps.** Tick a quest off for a friend, or for both of you, straight from the friends panel. Your code and your friends' codes now have their own panels.
- **Codex screenshot import on every tab**, Stencils and Designs included, with a list of what the screenshot doesn't show so a missing entry is easy to find.
- **Report a fact.** Right-click a fact and choose **Report** to send a correction. It's filed on the data repository for review.

## Changed

- **Found in** on item pages lists each container type and ARC once, by chance, with notes such as when to breach or which condition it needs, then each map once. ARC parts show only the spawns of the ARCs that drop them and the wrecks they're in, so the Turbine Compressor no longer lists every Bastion and Courier.
- **ARC drops** come from each ARC's own page, so the Hydra, Queen, Bully and Turbine have drop lists, and husks, probes and couriers hold only what's listed for them.
- **Container names** follow the game more closely: Medical Bag, Ammo Case, Backpack, Basket, First Wave Cache, Security Locker. These are still to be checked in game.
- Blueprint chips on recipes say when you've learned the blueprint.

Chances are a model built from container types, the loot areas around them and item rarity; the game publishes no drop rates. Distances are straight lines.
