# Design

Implements plan section 7: dark panels, one yellow accent, cream detail panel, rarity wedges, condensed uppercase headers, tabular numerals. Tokens live in `ui/src/lib/theme/tokens.css`.

- Fonts are Barlow and Barlow Condensed, bundled through Fontsource. No Embark fonts, logos or art.
- The background is an original CSS gradient, not a game capture.
- Rail glyphs are drawn inline. Item icons come from the runtime cache and fall back to initials.

The side-by-side comparison against in-game captures needs the screenshots in `docs/design/`, which are not in the repo yet.
